Calculadora de Descuentos

Manual técnico y operativo de usuario final verificado contra la aplicación real.

1. Para qué sirve la aplicación y quién la usa

La Calculadora de Descuentos es una herramienta web de cálculo inmediato diseñada para determinar el monto descontado y el precio líquido final a pagar en bolivianos (Bs), garantizando la aplicación rigurosa de las reglas comerciales de redondeo.

Público destinatario

  • Comerciantes y personal de ventas: Para cotizar rebajas en tiempo real sin riesgo de error de cálculo manual.
  • Compradores y clientes: Para comprobar con certeza el ahorro de una promoción y el monto exacto a desembolsar.

2. Guía paso a paso para calcular un descuento

Regla de tipeo importante: Ingrese exclusivamente números en los formularios. No escriba la palabra "Bs", signos monetarios ni el símbolo "%". Para números con centavos, use el punto decimal (.) del teclado para asegurar la compatibilidad con el navegador.

Paso 1: Identificar el formulario

Al acceder al sitio web observará el título central "Calculadora de Descuentos" y dos campos numéricos limpios.

Paso 2: Ingresar el precio original

Haga clic en la casilla "Precio original (Bs)". Escriba el valor de venta base del producto mayor a cero (por ejemplo, 200 o 150.75).

Paso 3: Ingresar el porcentaje de descuento

Haga clic en la casilla "Porcentaje de descuento". Digite un número entre 0 y 100 correspondiente a la oferta (por ejemplo, 25 para un 25 %).

Paso 4: Presionar el botón de cálculo

Haga clic sobre el botón "Calcular descuento". Notará que el botón cambia brevemente al estado "Calculando..." y queda deshabilitado para evitar peticiones duplicadas mientras la API procesa el resultado.

Paso 5: Interpretar el resultado

En la parte inferior se desplegará una tarjeta verde rotulada Resultado:

Resultado

Descuento aplicado: Bs 50,00

Precio final: Bs 150,00

3. Qué significan los mensajes de error y cómo resolverlos

Si algún valor viola las reglas de negocio, la aplicación detiene el envío y muestra una caja roja en la parte superior del formulario:

Error: "El precio original debe ser mayor que cero"

El precio original debe ser mayor que cero

Causa: La casilla de precio se dejó en blanco, se introdujo 0 o un valor negativo como -10.

Solución: Escriba un monto estrictamente mayor a 0 (por ejemplo, 0.01, 50 o 120.50) y vuelva a pulsar "Calcular descuento".

Error: "El porcentaje de descuento debe estar entre 0 y 100"

El porcentaje de descuento debe estar entre 0 y 100

Causa: Se escribió una cifra negativa (como -5) o una tasa superior al máximo permitido (como 150).

Solución: Modifique el porcentaje para que esté comprendido en el intervalo cerrado de 0 a 100 inclusive.

Avisos de estado en el pie de página

  • Comprobando conexión con la API...: Estado transitorio inicial al cargar la página mientras se verifica la salud del backend.
  • Conectado a la API en: producción (o local): El sistema backend está en línea y operando con normalidad.
  • Sin conexión con el servicio de cálculo: El backend no está accesible. Compruebe su conexión a internet o recargue el navegador transcurridos unos segundos.

4. Preguntas Frecuentes (FAQ)

1. ¿Puedo ingresar centavos en el precio?
Sí. La casilla admite hasta dos decimales utilizando el punto (por ejemplo: 99.99 o 33.33).
2. ¿Es válido un descuento del 0 % o del 100 %?
Ambos son valores válidos: al 0 % el precio final es idéntico al original (descuento Bs 0,00); al 100 % el precio final resultante es exactamente Bs 0,00.
3. ¿Cómo se redondean las fracciones de centavo?
Se aplica redondeo aritmético al centavo más cercano (mitad hacia arriba si el tercer decimal es 5 o superior). Por ejemplo, un precio de 33.33 con 10 % genera Bs 3,33 de descuento y un precio final de Bs 30,00.
4. ¿Cómo realizo un nuevo cálculo para otro producto?
No es necesario recargar la página. Seleccione el texto en las casillas, bórrelo, introduzca los nuevos datos y pulse nuevamente "Calcular descuento". El resultado verde se actualizará de inmediato.
5. ¿La aplicación guarda historial o emite facturas?
No. La aplicación realiza operaciones en tiempo real en memoria y no almacena datos de transacciones ni emite comprobantes descargables.
